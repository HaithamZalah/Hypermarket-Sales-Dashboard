# 🛒 Hypermarket Sales & Retail Performance Dashboard

## 📌 Project Overview
An end-to-end interactive Power BI dashboard analyzing multi-year hypermarket retail transactions. The dashboard provides strategic business insights across sales trends, product/brand performance, customer demographics, return rates, and interactive scenario testing (What-If Analysis).

---

## 📊 Key Performance Indicators (KPIs) & Insights
- **Total Sales:** $1.76M net sales generated.
- **Total Quantity Sold:** 833K units across all store types.
- **Gross Profit Margin:** Achieved a solid **59.26%** profit margin ($1.05M total profit).
- **Customer Base:** Served **9K active customers** with an average order value of **$30.22**.
- **Top Region:** **North West** leads total sales with over $547K.
- **Return Rate:** Maintained a low overall return rate of **0.99%** ($17.43K returned value).

---

## 💡 Advanced Features & Analytical Modules
1. **Executive & Sales Performance:** Drill-down capability from Annual trends down to Quarterly, Monthly, and Daily sales metrics.
2. **Product Analysis:** Multi-variable scatter plots analyzing price, quantity, and sales by brand (Top Brands: *Hermanos*, *Tell Tale*, *Ebony*).
3. **Customer Segmentation:** Analysis by membership card tier (Bronze, Silver, Golden, Normal) and occupation categories (*Professional*, *Skilled Manual*, *Management*).
4. **What-If Analysis (Scenario Modeling):** Dynamic price adjustment slider allowing executives to simulate profit impact (+/-% price increase) in real-time.
5. **Why Analysis (Decomposition Tree):** AI-powered root-cause analysis breaking down sales contributors by Year -> Region -> Store -> Product Brand.

---

## 🛠️ Tools & Technologies Used
- **Power BI Desktop:** Dynamic Dahsboard & Layout Design
- **DAX & Data Modeling:** Dynamic measures, scenario parameters, time intelligence, and KPI cards
- **Power Query:** Data transformation, cleaning, and table relationships
